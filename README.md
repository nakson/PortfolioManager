# 个人投资组合再平衡工具 (Personal Portfolio Rebalancer)

这是一个基于 Python Streamlit 的简单工具，帮助你：

1. **自动获取** 全球股票（美股、港股、A股）的最新价格。
2. **统一折算** 为美元 (USD) 计算总资产。
3. **智能计算** 每一笔新资金应该怎么分配，或者现有持仓如何调整，才能达到你的目标比例。

## 🚀 快速开始

### 1. 自动设置环境 (推荐)

在项目根目录下，直接运行 `setup.sh` 脚本：

```bash
bash setup.sh
```

该脚本会自动检测 Python 环境，创建 `.venv` 虚拟环境，并安装所有依赖。

### 2. 激活虚拟环境

在终端运行以下命令启用环境：

```bash
source .venv/bin/activate
```

激活后，你的终端提示符前应该会出现 `(.venv)` 字样。

### 3. 生成/重置数据文件

如果需要重新生成或重置数据：

```bash
# 确保已激活环境 (.venv)
python3 generate_data.py
```

### 4. 启动应用

```bash
# 确保已激活环境 (.venv)
streamlit run app.py
```

浏览器会自动打开 http://localhost:8501。

## ⚙️ 如何配置我的持仓？

打开生成的 `my_portfolio.xlsx` Excel 文件，包含以下列：

| 列名           | 说明                       | 示例                                                                                                                                                                                                                                                               |
| :------------- | :------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Ticker**     | 股票代码                   | 规则如下：<br>1. **美股/ETF**: 直接使用代码 (如 `VOO`, `NVDA`)<br>2. **港股**: 加后缀 `.HK` (如 `0700.HK`)<br>3. **A股(场内)**: 加后缀 `.SS`/`.SZ` (如 `600519.SS`)<br>4. **CNY场外基金**: 直接使用**6位数字代码** (如 `001632`)，系统会自动从天天基金网获取净值。 |
| **Shares**     | 你当前持有的股数           | `100`                                                                                                                                                                                                                                                              |
| **Target_Pct** | 你希望该资产占总资产的比例 | `0.2` (即 20%)。**注意所有行加起来必须等于 1.0**                                                                                                                                                                                                                   |
| **Currency**   | 该资产的计价货币           | `USD`, `HKD`, `CNY`                                                                                                                                                                                                                                                |

修改保存后，在网页上点击侧边栏的 **“刷新数据 (Reload Data)”** 按钮即可。

## 💡 功能亮点

- **自动汇率转换**：无需手动计算 CNY/USD 或 HKD/USD，系统实时获取汇率。
- **现金注入模式**：在侧边栏输入你想投入多少新资金，系统会自动计算买入建议。
- **缺口可视化**：红色代表需卖出（超配），绿色代表需买入（低配）。
